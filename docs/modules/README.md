# Module planning

Each new module or feature idea gets its own folder here, named in kebab case after the module, such as `settler-stories/`. The folder holds everything written while planning it: the plan, open questions, probe results, and later the spec.

Ideas start in [../research/ideas/module-ideas.md](../research/ideas/module-ideas.md). An idea gets a folder here when someone decides to work on it.
